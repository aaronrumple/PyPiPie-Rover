Getting started

Click Rover tab › Browse › Rover. The window opens beside Revit and stays open while you work (it is modeless). Clicking the button again brings the open window to the front, restoring it if it was minimized. After a pyRevit reload, clicking it replaces an old Rover window with the new version.

Rover reads the active document when it opens. On a large model the first load of Entire document takes a while (around 40 seconds for a model of about 38,000 elements); a splash screen shows while it loads. Switching tabs afterwards reuses what was loaded. Press Refresh after making changes in Revit.

The window follows Revit's dark or light UI theme (Revit 2024 and later), and switches when Revit does.

The window

The title bar shows a line that changes with what you are doing. The ? button beside minimize opens this help (or press F1).

The status bar along the bottom shows what Rover just did, with a Crafted by link on the left and the current theme on the right.

Under the title bar are the five tabs, followed by toolbar buttons that act on Revit:

ButtonWhat it does
Pick in RevitPick an element in the Revit view; Rover inspects it.
IsolateTemporarily isolates the highlighted rows (or the whole list) in the active view.
Zoom toSelects and zooms to the highlighted rows in the active view.
Select in RevitSelects the highlighted rows in Revit, or everything listed when none are highlighted.
RefreshRe-reads the model for the current tab.

The Document, Families and Warnings tabs share a three-pane layout:

TreeGroup by, filter, the tree, and a footer.
ListThe elements or types under the selected tree node, with its own filter.
InspectorParameters, API members and relations of the highlighted row(s) — where editing happens.

Every pane has its own filter box. Click its × or press Esc to clear it. Drag the dividers between panes to resize them.

Grouping

Group by offers Category › Family › Type, Category › Level, Level › Category › Family, Workset › Category, and View/Schedule › Category › Type.

Opening a view

Double-click a row to open a view that shows the element, select it and zoom to it. Rover prefers the view the row came from (in the sheet, view and schedule scopes), then the active view, then a view placed on a sheet (a plan on the element's level first), then other plans and a 3D view. Views, sheets and schedules simply open. Tags and other view-specific elements open their owner view.

Export

Export CSV saves the list as it is currently filtered.

Families tab

Every family and type in the model, grouped Category › Family › Type. Instances are never listed — a model can have far more types than instances.

KindMeaning
Loadable familyShown in the Project Browser under Families.
System familyWalls, floors, roofs, ducts, pipes, railings, stairs, filled regions… also in the Project Browser.
Internal typeTypes the Project Browser hides: text, dimension and view types, fluids, pipe schedules and similar.
  • Pick a type to edit its parameters or rename it.
  • Pick a family in the tree to edit or rename the family itself.
  • Duplicate type… creates a copy under a new name.

Search tab

Find value anywhere

Type any text and press Enter: Rover searches every instance and type parameter value in the chosen scope. Add a Category condition first on large models — it is much faster.

Query builder

Add condition rows of field · parameter · operator · value and choose Match all (AND) or Match any (OR).

  • Fields: Category, Family, Type, Name, Level, Workset, Element Id, Class, a specific Parameter, or Any parameter value.
  • Operators: contains, does not contain, equals, does not equal, starts with, ends with, greater than, less than, at least, at most, is empty, has value, matches regex.
  • Numbers use project units — 12', 3' 6" and 0 all work for lengths. Yes/No parameters accept yes/no.
  • Open the Parameter or Value list to see names and values found in the model.

Scopes: entire document, active view, active sheet, the current Revit selection, or the current Document list. Include element types also searches types.

Results

Select, Add to selection, Isolate, Export CSV, or Open in Document tab to browse and edit the results with the tree and inspector. Double-click a result to open a view showing it.

Saved searches

New / Save / Delete manage your searches; Import / Export share them as JSON files.

Warnings tab

Every Revit warning, grouped Warning › occurrence › affected element. Revit errors are prefixed [Error]; elements that are only involved (rather than causing a warning) are marked (additional).

  • Pick an element leaf to inspect it straight away — fix it in the inspector.
  • Double-click an element to open a view showing it.
  • Other groupings: Warning › Category, Category › Warning, Level › Warning.
  • Press Refresh after fixing to update the list.

Settings & Database

A Revit Lookup-style browser of the Application, Document, Project Information, Units, Phases, Worksets, Design Options, Object Styles, Line Styles, Fill Patterns, Materials, Project Location, elements by class, shared parameters, Extensible Storage schemas, registered updaters, links, CAD imports and warnings.

Blue values open the next level; ‹ goes back. Methods such as GetDependentElements() run when double-clicked.

Editing parameters

Highlight one row — or several — and edit in the Parameters tab of the inspector.

Value cellHow to edit
Text and numbersType and press Enter (or click away). Esc cancels. Numbers use project units, e.g. 10' 6".
Yes/NoClick the checkbox.
Drop-downCoded parameters (Function, Location Line, Wall Closure…) and element parameters (Type, Level, Phase, Material, Workset…). Pick an item, or type a name and press Enter.
Grey textRead-only — never written. Tick Editable only to hide these.

Instance and type

I marks an instance parameter, T a type parameter. Changing a type parameter changes every instance of that type — the tooltip says how many types are affected.

Many elements at once

Highlight up to 2,000 rows. Only parameters they all share are listed; differing values show <varies>. An edit is written to all of them in one step.

Patterns: different values for each element

Some values must differ from element to element — Name, View Name, Sheet Number, Mark. Type a pattern into a text value and Rover works out a value for each highlighted element. A preview lists the changes before anything is written, and the whole edit is one undo.

TokenBecomes
[Name]the element's current name
[Value]this parameter's current value on the element
[Mark], [Sheet Number], …any parameter of the element (or its type), by name
[Id] [Family] [Type] [Category]element id, family name, type name, category
[#] [##] [###]a running number padded to that many digits: 1, 01, 001… in list order
[##=5]a running number starting at 05
[Name|upper]modifiers: upper, lower, title, trim
[Name/old/new]replace text inside the value
[[ ]]a literal [ or ]
PatternCurrent nameResult
A-[Name]-01Door HeadsA-Door Heads-01
D[##] [Name|upper]Door Heads, Door JambsD01 DOOR HEADS, D02 DOOR JAMBS
[Name/Typ/Typical]Typ Wall SectionTypical Wall Section
[Sheet Number] - [Name]Plan (on sheet A101)A101 - Plan

Running numbers follow the list's current sort order. With several elements highlighted, the Name row accepts only patterns; Rover refuses a pattern that would give two elements the same name.

Name and API properties

The Name row renames types, views, levels, grids, materials, families, filters and similar elements — one at a time, or many at once with a pattern. The API members tab can also set writable properties such as Pinned and enum settings.

Undo: every edit is one Revit transaction named Rover: Set … — press Ctrl+Z in Revit to undo it.
Groups: elements inside model or detail groups are skipped with a message; Revit only allows those changes in Edit Group mode.

What element drop-downs offer

Element drop-downs list what the field can actually hold, even when every highlighted element is currently <None>:

  • View Template — templates of the selection's view type first, then all others marked with their type, e.g. Architectural Plan (Floor Plan). Schedules list schedule templates only.
  • Line Style — the styles Revit offers for that line.
  • Levels, phases, materials, fill and line patterns, arrowheads, profiles, mullion and panel types, scope boxes, family types — all of that kind in the model.
  • Family and shared parameters — by their declared type (Material, Image, a family type of a category).
  • Fittings (Bend, Tee, Cross…) — only <None> if no fittings of that kind are loaded.

Every list starts with <None>. Revit still checks each value when you apply it.

How coded drop-downs are filled

Revit has no API listing a coded parameter's names. The first time one is shown, Rover sets each code inside a transaction that is always rolled back and reads the name Revit displays, then caches the list. The model is never changed and no dialog appears.

Tips & troubleshooting

  • The list looks out of date — press Refresh. Rover doesn't track every change made in Revit.
  • "Revit did not accept" — the value isn't valid for that parameter, or a constraint (such as a top-constrained wall height) blocks it.
  • A type edit changed more than expected — it was a T parameter; undo with Ctrl+Z.
  • "Names must differ" — with several elements highlighted, Name only takes a pattern such as A-[Name]-01 or Door [##].
  • "Pattern gives the same name more than once" — add [#] or [Id] so each result is unique.
  • "No parameter named …" — a pattern token must match a parameter name exactly, as shown in the Parameters list.
  • A drop-down shows only <None> — nothing of that kind is loaded in the model (fittings, analysis display styles…).
  • Clicking Rover does nothing — the window may be behind Revit or on another monitor; the button now restores a minimized window.
  • Find value is slow — add a Category condition or narrow the scope.
  • The ribbon icon didn't update — Revit caches images per session; it updates after Revit restarts.
